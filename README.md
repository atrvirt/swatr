# SwATR — перемикач розкладки клавіатури

**Автор:** Andrii (ATR) Tarasenko  
**Версія:** 1.3.3 (див. [CHANGELOG.md](CHANGELOG.md))  
**Ліцензія:** MIT

Програма для Windows, що живе у системному треї та виконує перетворення тексту між українською та англійською розкладками клавіатури.

## Гарячі клавіші

| Клавіша | Дія |
|---|---|
| **Pause** | Перетворити останні набрані слова (з буфера введення) |
| **Shift + Pause** | Перетворити виділений текст через буфер обміну |
| **Правий Ctrl** | Швидке перемикання розкладки EN ↔ UA |
| **Ctrl + `** | Відкрити історію буфера обміну |

## Функціонал

- **Конвертація тексту** — автоматичне визначення напрямку (UA→EN або EN→UA) за наявністю кириличних символів; регістр символів зберігається (Shift і CapsLock)
- **Авто-перемикання розкладки** — після конвертації розкладка автоматично перемикається під мову результату
- **Міні-сповіщення** — результат конвертації показується ~1,2 с у кутку екрана, без крадіжки фокусу
- **Трей-іконка** — відображає поточну розкладку (`EN` синім, `UA` жовтим); підказка перераховує всі гарячі клавіші
- **Перевірка середовища** — програма не запускається за відсутності української розкладки в системі
- **Автозапуск** — налаштування запуску зі стартом Windows через діалог «Про програму»

## Вікно історії буфера обміну

- Зберігає до 64 записів (текст і зображення), не допускає дублів
- Список з пошуком / фільтром у реальному часі
- Права панель — перегляд тексту або зображення
- **Enter** або подвійний клік — вставити запис у попереднє вікно
- **Delete** — видалити запис
- **Esc** або втрата фокусу — закрити без дії
- Історія зберігається у файлі `SwATR.dat` поруч з exe (бінарний формат)

## Діалог «Про програму»

- Іконка-логотип програми (UA / EN, кольори прапора)
- Версія, автор, ліцензія
- Список гарячих клавіш
- Checkbox **Запускати при старті Windows** (запис до `HKCU\...\Run`)

## Технічні деталі

- Реалізовано на **Delphi 13 (RAD Studio, Florence)**, VCL, Win32
- Глобальний хук `WH_KEYBOARD_LL` (без окремої DLL)
- Жодних блокуючих очікувань у потоці хука — усі паузи через прокачку повідомлень (`WaitPump`), інакше Windows гальмує ввід усієї системи і знімає хук
- Маркер `SWATTR_MAGIC` у `dwExtraInfo` — запобігає повторній обробці синтетичних подій
- Моніторинг буфера обміну через `AddClipboardFormatListener` (Vista+)
- Автозапуск через `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
- Іконка генерується програмно через GDI (`CreateIconIndirect`)
